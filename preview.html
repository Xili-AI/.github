我们是谁　苏州矽励科技有限公司（Silicon Insight Technology）是一家专注 视觉智能 与 大模型应用 的技术团队。我们把计算机视觉的前沿能力与大语言模型的推理能力相结合，用工程化方法把它们沉淀为可交付、可落地的产品系统。

👁 视觉智能

图像 / 视频理解、目标检测与分割、OCR、视觉大模型微调与评测，服务真实场景下的感知与标注需求。

🧠 大模型应用

以 RAG 为核心的知识库工程、实体与关系抽取、智能体编排、模型微调与推理加速，把模型能力转化为业务生产力。

⚙ 工程交付

从数据治理、标注流水线到服务端架构与可观测性，交付稳定、可维护、可扩展的端到端系统。

PROJECTS

🔒 PRIVATE

Xili-ReportRAG

质量部知识库管理系统。基于 LLM + 向量检索 + 知识图谱，面向半导体与电子制造行业，从 8D 质量报告中抽取实体与关系，构建可查询的知识图谱，支持混合检索、以文/以图搜图、RAG 流式问答、AI 根因推理与 8D 报告生成。

STACK

Python Flask SQLAlchemy MySQL Qdrant Neo4j Qwen3-VL-Embedding MinerU Vue 3 TypeScript Naive UI ECharts uv Docker

闭源仓库，仅组织成员可访问。

AutoLabel

桌面端自动标注 / 模型训练工具。基于 tkinter + ultralytics YOLO，覆盖预训练权重加载、数据集准备、自动标注、模型训练与训练曲线查看的完整闭环，配套 Labelme 标注与数据集切分规范。

STACK
